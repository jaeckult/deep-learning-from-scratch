Calculus for backprop

Compressed from Lesson 0001. Keep this open while writing engine.py.

The rule

dz/dx = dz/dy · dy/dx     (chain rule: multiply sensitivities along the chain)

The gotcha

If a Value is used more than once, its gradient is the sum across every use, not the value from the last use: 

self.grad += local_derivative * out.grad   # always +=, never =

This is the single most common bug in a hand-built autograd engine. If gradcheck fails only on expressions that reuse a variable (b = a + a, or anything shaped like it), this is why.

Local derivative of every op you need

opforwardlocal derivative
addc = a + bdc/da = 1, dc/db = 1
multiplyc = a * bdc/da = b, dc/db = a
powerc = a**ndc/da = n · a**(n-1)
expc = e**adc/da = c (itself)
logc = ln(a)dc/da = 1/a
tanhc = tanh(a)dc/da = 1 − c²
reluc = max(0, a)dc/da = 1 if a > 0 else 0
sigmoidc = 1/(1+e^-a)dc/da = c · (1 − c)

Notice a pattern: tanh, relu, and sigmoid all have local derivatives expressible in terms of their own output c, not the raw input a. That's why Value.backward() only ever needs self.data (its own cached forward value) to compute its contribution — you never need to recompute or re-store the input.

Sigmoid + binary cross-entropy shortcut

Worth memorizing, since you'll rederive it constantly: for p = sigmoid(z) and BCE loss against label y ∈ {0,1}, 

dL/dz = p - y
