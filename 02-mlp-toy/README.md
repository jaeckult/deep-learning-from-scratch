# 02 — Tiny MLP, synthetic 2D classification

`Neuron` → `Layer` → `MLP` built on the `01-autograd` engine. Manual SGD
loop: forward, `loss.backward()`, step, zero grad.

**Dataset:** synthetic, two features shaped like a trading signal pair
(e.g. "short-horizon momentum" x "order-book imbalance"), with a label
generated by a nonlinear rule you pick (two interleaved arcs / XOR-ish
region + noise — `sklearn.datasets.make_moons` is a fine drop-in if you'd
rather not hand-roll the generator). Keep it synthetic on purpose: you need
a *known* nonlinear boundary to prove the MLP learned something a linear
model can't. This is a toy for the mechanism, not a claim about real
signal — don't read anything into the "accuracy" beyond "did backprop
work."

**Correctness check:** loss drops monotonically; decision boundary plot
visibly separates the two classes; a single-layer (linear) model fails to
separate them where the MLP succeeds.
